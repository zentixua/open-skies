### Installation

- `Open-Skies.zip` — a [Prism Launcher](https://prismlauncher.org/download/) instance that updates the pack before every game launch: "Add Instance…" → "Import" → this file.
- `Open-Skies.mrpack` — a one-time installation of this version without automatic updates: import it in Prism Launcher or Modrinth App.
