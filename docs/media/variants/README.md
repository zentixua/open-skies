# Brand-set variants (draft, not for main)

Mission pack-brand-2: the owner asked for the pack's look to put Incoming at its centre ("the pack was made for this
mod"). This folder holds 3–4 complete variants side by side; the owner picks or corrects one, then only that one
replaces `docs/media/` and this folder is removed before merge.

Plan:
1. Concept study: what the pack is, how packs built around one flagship mod brand themselves, how far to lean on
   Incoming's identity (letterforms, palette, motifs).
2. Variants, each: pixel icon (32×32, Incoming's style), GitHub banner, store icon and store banner from in-game
   frames only (Modrinth rule 6.2), feature strip / README top.
3. Comparison sheet at real sizes (64 px launcher icon, store card, GitHub header), judged by a fresh Claude session.
