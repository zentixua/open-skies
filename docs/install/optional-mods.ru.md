# Установка Open Skies

`Open-Skies.zip` — экземпляр Prism Launcher, который обновляет сборку перед каждым запуском игры. В Prism выбрать
«Добавить экземпляр…» → «Импорт» → этот файл. В экземпляре версии Minecraft и NeoForge из сборки и 6144 МБ памяти.
Первый запуск скачивает моды и спрашивает, какие необязательные моды установить.

`Open-Skies.mrpack` — разовая установка одной версии в Prism Launcher или Modrinth App, без автообновления.

## Необязательные моды

| Название в установщике | Описание |
|---|---|
| Flashback | Запись и повтор (Flashback): нужно только тем, кто снимает |
| Flashback Neoforge Fixed | Запись и повтор (Flashback): нужно только тем, кто снимает |
| Sinytra Connector | Запись и повтор (Flashback): нужно только тем, кто снимает |
| Roxy | Дальняя прорисовка (Roxy и Voxy — только вместе): нужна OpenGL 4.6, на macOS выключить оба |
| Voxy | Дальняя прорисовка (Roxy и Voxy — только вместе): нужна OpenGL 4.6, на macOS выключить оба |

Для записи включить все три мода записи вместе. Roxy и Voxy включены по умолчанию в экземпляре с автообновлением.
При импорте `.mrpack` Prism предлагает необязательные моды выключенными: отметить Roxy и Voxy, кроме macOS.

На следующих запусках выбор меняется кнопкой «Optional mods...» в packwiz-installer. Галочки модов сборки на странице
«Моды» Prism не менять: packwiz-installer вернёт их.

Установщик показывает русские описания сборки. Он читает одну строку `option.description` на мод;
в [формате packwiz](https://packwiz.infra.link/reference/pack-format/mod-toml/#option) нет поля описания для каждого языка.
[Окно выбора модов установщика](https://github.com/packwiz/packwiz-installer/blob/main/src/main/kotlin/link/infra/packwiz/installer/ui/gui/OptionsSelectWindow.kt)
показывает эту строку напрямую. Отдельная английская страница даёт перевод описаний, но не переключает язык установщика.
