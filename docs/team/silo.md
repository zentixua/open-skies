# Silo server (team reference; rules in .claude/rules/team.md)

Artem's Zearth Silo server (25567) rebuilds the "Silo" series' silo complex to replay the S3E09 nuke. His rules:
- Full 1:1 scale, no exceptions (Artem, 12.11); only real data from the show and its sources, no guesses.
- One open plain, no teleports; no visible difference from the show's frames.
- Every swap, restart or golden reset needs his line; he may be playing.
Layout numbers, the golden world version and live status: the lead's project memory (`silo-complex-25567`).
Spec and tools: `tools/silo/` (draft PR #52 until merged). References: the lead's Silo reference library.
