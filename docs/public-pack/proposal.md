# Public modpack built around Incoming: proposal (draft)

Status: draft, research in progress. Nothing here is published or implemented.

## Plan
1. Research how well-regarded pack makers work (philosophy, balance, performance baseline, configs, quests, sides,
   versioning), with sources.
2. Formats and distribution: packwiz, Modrinth `.mrpack`, CurseForge; launcher import paths; template-friendliness.
3. Licenses and redistribution for every candidate mod (Modrinth and CurseForge rules), with Voxy/Roxy,
   Create Aeronautics/Sable, Immersive Aircraft, shaders and Incoming as the critical cases.
4. Two to four pack variants with mod lists by role, first hour/week, PC requirements, pros/cons, maintenance cost;
   one recommended.
5. Name options checked against Modrinth, CurseForge and GitHub.
6. Repository structure: public upstream repo plus this private repo as its fork; CI for both.
7. Honest verdict: weak points, costs, failure modes.
