# Changelog

Each released version of Open Skies. A new `version` in `pack/pack.toml` needs its section here; CI builds the
GitHub release notes from it (`tools/release_notes.py`).

## 1.0.1

- Incoming 3.14.0: a new nuclear dust wave, buildings that fall when a strike knocks out their support, flash fires,
  and redstone, Create Display Link, Jade and computer support
  ([release notes](https://github.com/zentixua/incoming/releases/tag/v3.14.0)).

## 1.0.0

First public release.
- Core: Create 6.0.10 with Sable and Create Aeronautics, Incoming 3.13.0, Immersive Aircraft and Man of Many Planes,
  Create Big Cannons, Vic's Point Blank, Propulsion and Aeroworks.
- Survival and exploration: YUNG's structures, Towns and Towers, Farmer's Delight with Create: Central Kitchen,
  Sophisticated Backpacks and Storage, Lootr, Comforts, AppleSkin.
- Servers: Open Parties and Claims, Simple Voice Chat (optional), Chunky, LOD Server Support.
- Long-distance rendering: Voxy through Roxy, on by default.
- Shaderpacks to choose from (none selected): Photon, Complementary Unbound with Euphoria Patches, MakeUp Ultra Fast.
